# Control de almacén

App de inventario donde solo se agregan y se quitan productos. Los datos se guardan en el navegador (localStorage).

## Comandos

```
npm install        # instala dependencias
npm run dev        # servidor de desarrollo (http://localhost:5173)
npm run build      # genera la carpeta dist
npm run preview    # prueba el build (http://localhost:4173)
```
